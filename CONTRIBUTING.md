# Contributing to Pockeva

Thank you for wanting to help. Pockeva is proprietary software and its source code is not published in this repository, so this repository holds the project page, documentation and release information. You can help in these ways.

## Report a bug

Use the [bug report form](https://github.com/itspabel/Pockeva/issues/new?template=bug_report.yml). Before you open one:

- Search the open and closed issues to see if it was already reported.
- Update to the latest release and check that the problem is still there.

A good report has the Pockeva version, Android version, device model, the steps to reproduce, what you expected and what happened. Add a screenshot if it helps.

## Suggest a feature

Use the [feature request form](https://github.com/itspabel/Pockeva/issues/new?template=feature_request.yml). Describe the problem you are trying to solve first, then the behavior you would like. One focused idea per issue is easiest to track.

## Privacy when you report

Issues are public. Never post:

- Passwords, PINs or financial account credentials.
- Backup files or exported PDF reports with real data.
- Screenshots that show private balances or personal details. Hide them first.

Report security problems privately, see [SECURITY.md](SECURITY.md).

## Pull requests

There is no application source code here, so pull requests are not accepted for the app. If you spot a typo or a mistake in the documentation or the project page, open an issue and describe the fix.

## Code of conduct

Everyone taking part is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
