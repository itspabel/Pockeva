Get Pockeva for Android

Pockeva is an APK distributed through GitHub Releases, not Google Play. Compatibility can vary by device and Android version.

Download for AndroidGitHub Repository
  1. Open the release page.
  2. Download the APK asset.
  3. Open the downloaded file and follow Android's installation prompts.
  4. If Android requests permission to install unknown apps, allow it for the relevant installation source only if you trust the APK.

Offline-first by design

According to Pockeva's in-app privacy policy, your financial records are stored locally, no account is required, and the app does not use analytics, advertising networks, or telemetry. Backups and PDF reports are generated locally.

These statements reflect the in-app privacy policy and are not an independent audit. This landing page does not collect financial data, require registration, or use tracking scripts.
