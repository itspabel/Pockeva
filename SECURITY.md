# Security Policy

## Supported versions

Security fixes are released for the latest version only. Older versions do not receive patches.

| Version | Supported |
| ------- | --------- |
| Latest release | Yes |
| Older releases | No |

Always update to the newest release before reporting a security issue.

## Reporting a vulnerability

**Do not report security vulnerabilities through public GitHub issues.**

Report privately through [GitHub Security Advisories](https://github.com/itspabel/Pockeva/security/advisories/new). If you cannot use that form, email <hello@pabel.pro.bd>.

Please include:

- The type of issue and where in the app it happens.
- The Pockeva version, Android version and device model.
- Step-by-step instructions to reproduce it.
- The impact, including how someone could take advantage of it.

You will get a reply as soon as possible. Please do not disclose the issue publicly until a fix has been released.

Do not include real financial data, account credentials or private backup files in your report.

## Official downloads

Pockeva APKs are published only in the [Releases](https://github.com/itspabel/Pockeva/releases) section of this repository and on the [Pockeva website](https://pockeva.asf.run). An APK from any other source is not an official build, so do not install it.
